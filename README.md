# Auto Clicker Deluxe

A simple Python autoclicker using PyAutoGUI and Keyboard.

## Features

* Set your desired CPS (Clicks Per Second).
* Press **F6** to toggle the autoclicker ON/OFF.
* Press **F7** to change the CPS.
* Simple command-line interface.

## Requirements

* Python 3
* PyAutoGUI
* Keyboard

## Installation

Install the required libraries:

```bash
pip install pyautogui keyboard
```

## Usage

Run the script:

```bash
python main.py
```

Enter your desired CPS when prompted.

### Controls

| Key | Function                  |
| --- | ------------------------- |
| F6  | Toggle autoclicker ON/OFF |
| F7  | Change CPS                |
